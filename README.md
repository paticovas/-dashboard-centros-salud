# Dashboard · Centros de salud tipo A, B y C (Ecuador)

Página estática para GitHub Pages. Lee los datos en vivo desde QGIS Cloud:

- Mapa (WMS): https://wms.qgiscloud.com/Paticovas/MapaWeb_CentrosSalud/
- Datos (WFS, capa `centros_salud`) para los conteos por provincia, cantón y tipo.
- Visor QGIS Cloud: https://qgiscloud.com/Paticovas/MapaWeb_CentrosSalud/

Para actualizar las estadísticas basta con editar la tabla `centros_salud_abc` en QGIS Cloud;
no hace falta volver a subir esta página. Si QGIS Cloud no responde, la página usa una copia de respaldo incluida.
